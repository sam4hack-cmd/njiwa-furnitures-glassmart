# Njiwa Furnitures & Glassmart Website

A simple, responsive storefront for Njiwa Furnitures & Glassmart with:

- Home page with product catalog
- Owner admin page to add products
- Contact page with business info and map location
- Order placement page for customers
- Responsive, modern design

## Files

- `index.html` — home landing page and products
- `orders.html` — order form
- `contact.html` — contact details and map
- `admin.html` — owner page to add products
- `styles.css` — site styling
- `script.js` — product and order logic using localStorage

## How to run

Open `index.html` in your browser.

If you want, you can also host it with GitHub Pages or any static hosting service.
